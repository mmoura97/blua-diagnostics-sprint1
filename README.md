# BluaDiagnostics — Sprint 1

Projeto acadêmico desenvolvido para o Challenge BluaDiagnostics.

## Estrutura

- notebooks/: PoC em Google Colab
- prompts/: system prompts
- evals/: conjunto de avaliação
- tools/: tools simuladas
- docs/: documentação e arquitetura
- src/: código auxiliar
- knowledge_base/: base mockada

## Execução

### Google Colab

Abra:

notebooks/sprint1_poc.ipynb

Configure o Secret:

OLLAMA_API_KEY

Instale dependências:

pip install ollama
